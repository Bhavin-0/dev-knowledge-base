# Linux Quick Notes

## 1. Remove a File

### Syntax

```bash
rm <file_name>
```

### Example

```bash
rm notes.txt
```

### Common Flags

- `-r` : Remove directories recursively.
    
- `-f` : Force deletion without confirmation.
    

### Example (Delete a Directory)

```bash
rm -rf myFolder
```

### Warning

```bash
rm -rf *
```

Deletes **all files and folders** inside the current directory.

---

## 2. Find a Directory

### Syntax

```bash
find . -type d -name "<directory_name>"
```

### Example

```bash
find . -type d -name "Forge"
```

### Explanation

- `find` : Search utility.
    
- `.` : Start searching from the current directory.
    
- `-type d` : Search only for directories.
    
- `-name` : Name of the directory to search for.
    

---

## 3. Find a File

### Syntax

```bash
find . -type f -name "<file_name>"
```

### Example

```bash
find . -type f -name "notes.txt"
```

### Explanation

- `find` : Search utility.
    
- `.` : Start searching from the current directory.
    
- `-type f` : Search only for files.
    
- `-name` : Name of the file to search for.
    

---

## Useful Variations

### Find files with a specific extension

```bash
find . -type f -name "*.java"
```

### Case-insensitive search

```bash
find . -type f -iname "notes.txt"
```

### Find directories only

```bash
find . -type d
```

### Find files only

```bash
find . -type f
```
